## Boundaries that remain open

The document design is complete; learner execution remains unassessed. Two depth tasks await methods access. Recursive citation closure is incomplete, and inherited persona attributions are not all independently verified. The bibliography is preserved as a research queue. A proposed contribution is not merged work; an integration proposal is not an employment offer.

Exact IDs, hour accounting and detected exact-title overlaps are checked. Semantic overlap is managed through shared owners and distinct acceptance regimes, but an exhaustive no-overlap claim would be stronger than the evidence. If two future assignments produce the same invariant and artifact, merge them and update the ledger rather than charging both.

Some book chapter numbering and inherited resource entry points still require checking against the learner’s edition or pinned software version. The active guide identifies scope and the JSON retains provenance. The 129 curated resource selections replace erroneous broad text matching.

## Reproduction

Extract the ZIP into a working folder, keeping its directories. Python dependencies are `python-docx`, `PyMuPDF` and `Pillow`; rendering also needs LibreOffice and a DOCX renderer. Run these in order:

```bash
python work/v54/build.py
python work/v54/enrich.py
python work/v54/curate.py
python work/v54/render.py
python work/v54/evidence.py
python work/v54/validate.py
```

`render.py` creates the DOCX and Markdown. Render the DOCX to `work/v54/delivery_render/frontier-v54-curriculum.pdf` with the Documents renderer or LibreOffice; then run `layout.py` for page/title/bounds checks and review the generated images. Regeneration does not imply that visual review has already been repeated.

Primary career references are linked in the curriculum. They were checked for this revision; recheck exact job eligibility and annual visa thresholds when applying.
